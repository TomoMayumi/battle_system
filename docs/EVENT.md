# 金曜の打ち上げ進行案

## 前提

初期案は新人13人＋講師2人、約2時間。人数は開始前に4〜64人で設定可能です。食事が最初からあるなら乾杯後に食事、コース提供なら一通り食べ終えてから対戦開始。参加や応援を強制しない。景品は主催者が用意。

Switch 2を1台、プロジェクター1台で全員が同じ対戦を見る構成。Web用タブレットは司会者の入力端末。映せる場合だけ表彰時に投影し、対戦中はSwitch画面を優先します。2台目は別画面・ソフト・進行役が必要なので標準案では使いません。

## 事前チェック

- マリオパーティの正式タイトル、所有ソフト、Joy-Con/Joy-Con 2の世代を確認。
- Joy-Con左右4組を片側8個として使う想定。ただしモードごとの人数・片側対応・追加機器は実機で確認。8個あるだけでは8人同時対戦になりません。
- 個人4人戦で順位が付く、説明が短いミニゲームを試走。操作が単純なものを中心に、連打・反射神経だけに偏らず選びます。チーム戦・協力ゲームは採点外。
- 1枠1本／2本の実測時間と交代時間を確認。Webにゲーム結果の自動取得機能はありません。
- ドック・ACアダプター・HDMI・コントローラー充電・ストラップ・予備電源を持参。
- 会場のHDMI接続、音量、設置場所、ケーブル長を確認。タブレットの映像出力は機種/変換器次第で、USB-C端子だけでは保証できません。
- Wi-Fi専用タブレットはテザリングを用意。参加者のモバイル回線が会場内で通ることを確認。
- 本番URLとQRコード、紙の結果控え、紙の対戦表、景品を用意。

公式のモード・対応機器はこの作業では確定できていません。実機確認まではジャンボリーTVなど特定モードや追加機器が使える前提にしないでください。追加ソフトは所有していればマリオカートの短いレースなどを採点外のお楽しみ枠にできます。

## 時間の選び方

| 対戦に使える時間 | 本数                                                         |
| ---------------- | ------------------------------------------------------------ |
| 約60分以上       | 15枠×2本。全員8本。1枠約4分の試走結果が目安                  |
| 約40〜50分       | 15枠×1本。全員4本。説明・交代・表彰の時間も確保              |
| それ以下         | 実測時間で成立するか確認。無理なら採点なしのお楽しみ会へ変更 |

表は15人の場合の目安。予定対戦数は1〜200で設定でき、開始後も対戦を追加できます。時間切れなら「途中終了」で記録済みの本数から集計。人数・本数に差が出た場合も、順位は平均得点、同点なら1位率で比較します。未参加者は対象外なので、可能なら全員の出番を確保してください。

## 当日の流れ

1. 乾杯・食事・歓談。ゲームに残せる時間を確認。
2. 主催者がニックネームを改行区切りで一括登録し、人数・予定対戦数・本数・表彰人数を設定。QRコードを共有。
3. 採点ルールを説明。同率順位で表彰対象が増える場合の景品の扱いを決めておく。
4. 練習は採点外。ゲームを知らない人にも操作を試してもらう。
5. 保存して開始。現在と次の4人を読み上げ、参加者または司会が「結果入力」で記録。間違えたら「直前の入力を修正」。重複入力を避けるため、その本を入力する人を決めておきます。
6. 可能な範囲で講師を別枠にし、プレイしていない講師が進行・記録を担当。少人数や交換時は同じ枠になる場合があります。
7. 食事・離席に合わせて休憩。未記録の対戦は司会の「この対戦の出場者を変更」で登録済みの代役に交代可能。「以降の出番も調整」で代役の次の交換可能な枠も入れ替えます。交換先がなければ以降はそのまま。1本でも記録済みの対戦は交代不可です。未実施の出番は従来の相互交換も可能。
8. 余裕があれば対戦を追加。時間切れなら途中終了。実施本数・平均点・未参加者・表彰人数を確認してから確定。確定後は再開や延長ができません。
9. スマホまたは投影で表彰。JSON/CSVを書き出して終了。

静かな参加者にも大きなリアクションを求めず、自然に短い会話が生まれる進行にします。順位は閲覧できても、人をいじったり飲酒・罰ゲームと結び付けたりしません。
