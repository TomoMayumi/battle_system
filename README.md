# おつかれさま杯

新人13人・講師2人の打ち上げ用。スマホで出番と順位を閲覧し、司会者がミニゲームの結果を入力します。

## 公開先

- Web: https://battle-system-tm-20261014.web.app/
- GitHub: https://github.com/TomoMayumi/battle_system
- Firebase: `battle-system-tm-20261014`、無料Spark、Firestore東京（asia-northeast1）。
- Google認証設定: https://console.firebase.google.com/project/battle-system-tm-20261014/authentication/providers

利用前にGoogleログインを有効化し、主催者が公開サイトでイベントを作成してください。参加者には作成後のイベント閲覧URLを共有します。

## ローカルで試す

Node.js 22.12以上とnpmを使用します。

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 5182
```

http://127.0.0.1:5182/ を開き、「司会」で名前・1枠の本数・表彰人数を設定して「保存して開始」。Firebase未設定時は端末内の試用データです。別スマホとは共有されません。

Firebase設定後も `?demo=1` でローカル試用できます。試用データとクラウド結果は別保存です。

## 本番公開

[Firebase無料プランの設定・公開手順](docs/FIREBASE.md)を参照してください。Hosting・Firestore・Authenticationのみを使い、Sparkのまま公開します。主催者のGoogleログインとFirebaseプロジェクト設定は必要です。

## 当日の操作

- 主催者は作成したイベントURLを保管。イベント一覧は自動取得しません。
- 参加者はQRコードの閲覧URLを開き、自分の名前を選択。
- 司会者はゲーム名と4人の順位を入力。保存後は次の未記録本へ移動。
- 過去の対戦を選択して訂正・取消可能。履歴は最新100件を保存。
- 未実施の2枠で出番を相互交換。参加回数と講師別枠の条件を維持。
- 全結果が揃うと「順位を確定」が有効。確定後は結果と表彰人数を変更できません。
- タブレットは入力端末として利用。共有メニューの投影画面は接続できた場合だけ使用。

時間配分と機材確認は[イベント進行案](docs/EVENT.md)にまとめています。

## 採点・対戦表

4人戦15枠。全員4枠で、1枠1本なら1人4本、2本なら8本。初期対戦表では連続出番なし、各人が1P〜4Pを1回ずつ担当し、講師2人は同時にプレイしません。相手の組合せには繰返しがあり、総当たりではありません。出番交換後の連続なし・席位置の均等までは保証しません。

1〜4位は4・3・2・1点。同着は占有する順位の平均点。例：1・1・3・4位なら3.5・3.5・2・1点。合計点、次に1位回数で順位を決め、それも同じなら同率順位。表彰は順位が1位以内／3位以内の全員を表示するため、同着で人数が増えることがあります。景品の扱いは当日説明してください。

## 保存・障害対応

クラウドは1イベント1ドキュメント。更新時はトランザクションとrevisionで競合を検出。閲覧は変更購読で、秒ごとの全件取得は行いません。再接続やルール評価にも読取が発生するため、使用量はFirebaseコンソールで確認してください。

未送信入力は入力した端末に保存し、再読み込み後も復元。復旧後は「再送」。別端末の更新と衝突したら自動上書きせず、未送信を書き出してから入力を取消し、最新結果を確認して手動で反映します。未送信付きバックアップは直接読込できません。JSON内の `unsent` と `event` を控えとして使えます。

共有済みデータはJSONバックアップと順位CSVに書き出せます。バックアップ読込は、クラウドでは新しいイベントを作り、ローカルでは試用データを置き換えます。確定済みを読み込んでも確定状態を維持。有料自動バックアップ機能は使いません。

最初に画面を読み込めていればキャッシュ表示できますが、初回アクセス・ログイン・クラウド保存には通信が必要。障害時は紙で対戦番号・本数・4人の順位を控え、復旧後に入力してください。

## 検証

```powershell
npm test
npm run lint
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:rules
npm audit --omit=dev
```

ルールテストはJava 21以上が必要。`demo-party-night` のローカルエミュレーターだけに接続し、本番データには触れません。ブラウザーテストはPC・スマホ・タブレットのChromiumで実行。生成物は `test-results` に保存します。

Firebase CLIは開発用です。最新版でも一部推移依存に監査警告があるため、未信頼の設定・パターンを使わず、公開前に `npm audit` を再確認してください。本番サイトにCLIは配布しません。
